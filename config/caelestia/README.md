# Caelestia user settings

`shell.json` contains the shared preferences currently used by this setup. `hypr-user.lua` sets the user's shared Swedish keyboard layout. Caelestia's own shell and generated Hyprland configuration are installed and updated upstream; they are not copied into this folder.

Caelestia creates `hypr-vars.lua` when needed; it is omitted because the original file had no overrides. Add only supported, hardware-independent variables to the shared profile. Keep monitor output names and hardware-dependent choices in the ignored `host-local/<pc-name>/` folder.
